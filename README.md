# Problem Statement and its ill-posed nature
Given a single image $\bf{I}$ captured through a reflective surface (like glass), estimate:  
Transmission layer $\bf{T}$: the actual scene behind the glass and  
Reflection layer $\bf{R}$: the unwanted reflections on the camera's side

* <u>Why is it ill-posed?</u>  $\bf{I = T + R}$; One equation, but two unknowns


Link to reference papers:  
1.⁠ ⁠Zhu et al., Revisiting Single Image Reflection Removal In the Wild (Main Paper): https://arxiv.org/pdf/2311.17320
